## 1. Übung (Postleitzahlen prüfen)

**Schreibe einen ERE-Ausdruck für österreichische Postleitzahlen.**

**Regeln:**
- **genau 4 Ziffern**
- **erste Ziffer darf nicht 0 sein**

**Gültig:**
```
4020
5280
1010
```
**Ungültig:**
```
0123
123
12345
abcd
```

----

Man verwendet wieder `grep` und `-E` für die Extended Regular Expressions danach macht man `^` für den Anfang der Zeile. Die erste Ziffer darf dann nur von `1-9` gehen, da 0 ja nicht erlaubt ist. Danach müssen 3 weiter Ziffern folgen, also `[0-9]{3}` danach schließt man den command mit einem `$` für das Ende der Zeile.

Wenn man dann die gültigen Postleitzahlen eingibt, so bekommt man diese wieder zurück geliefert, nur diesmal mit roter Schrift, sind sie jedoch ungültig werden sie nicht zurückgeliefert:
```
┌──(kali㉿kali)-[~]
└─$ grep -E '^[1-9][0-9]{3}$'               
4020
4020
5280
5280
abcd
0123
```
