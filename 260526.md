# 1. Zusammenfassung der Theorie

Es wurden die Linux-Befehle `grep` und `sed` verwendet. Diese Ausdrücke ermöglichen es, flexibel nach bestimmten Mustern in Dateien zu suchen oder Texte zu verändern. 

Mit `grep` können bestimmte Inhalte aus Dateien herausgefiltert werden, wie hier:

```
grep 'Werkstatt' klassenkassa.csv
```

zeigt alle Zeilen an, die das Wort „Werkstatt“ enthalten.

Der Punkt `.` steht in Regex für ein beliebiges Zeichen:

```
grep 'W.' klassenkassa.csv
```
Hier werden daher alle Wörter gefunden, die mit `W` beginnen und mindestens ein weiteres Zeichen besitzen, z. B. „Walter“ oder „Werkstatt“:
```
Sophia,22.09.2023,15.0,Werkstatt
Lena,18.09.2023,13.0,Werkstatt
Emma,22.09.2023,42.0,Werkstatt
Nico,18.09.2023,23.0,Werkstatt
Timo,25.11.2023,5.0,Walter
```

Das Zeichen `*` bedeutet, dass das vorherige Zeichen beliebig oft vorkommen darf, also auch 0-mal:

```
grep 'W.*' klassenkassa.csv
```

findet alle Wörter, die mit `W` beginnen:
```
Laura,28.10.2024,3.21,Werkstatt
Jan,30.11.2024,2.56,Walter
Benjamin,25.11.2024,15.78,Werkstatt
Paul,14.11.2024,11.92,Walter
```

Das Zeichen `+` bedeutet, dass das Zeichen davor mindestens einmal vorkommen muss. `sed` versteht `+` jedoch nur mit `-E` für expandend:
```
┌──(kali㉿kali)-[~]
└─$ echo 'jhabbbaabgfah' | sed -E 's/[ab]+/XYZ/'
jhXYZgfah
```

Mit `[ ]` werden Zeichenklassen definiert:
```
┌──(kali㉿kali)-[~]
└─$ grep '1[0-9]\.[0-9][0-9]\.' klassenkassa.csv
Lena,18.09.2023,13.0,Werkstatt
Lukas,15.09.2023,2.5,Kino
Nico,18.09.2023,23.0,Werkstat
```
sucht erstmal nach Zahlen von 10-19 mit Punkt dahinter und daraufhin zwei Zahlen von 0-9.

Mit `grep -o` wird nur der eigentliche Treffer ausgegeben und nicht die gesamte Zeile:
```
┌──(kali㉿kali)-[~]
└─$ grep -o '1[0-9]\.' klassenkassa.csv
15.
18.
13.
15.
18.
10.
```

Außerdem wird `sed` verwendet, um Texte zu ersetzen.:
```
┌──(kali㉿kali)-[~]
└─$ echo '1234ccbbaa1234' | sed 's/ccbbaa/XYZ/'
1234XYZ1234
```

Der Befehl `sed` funktioniert folgendermaßen:

```
s/ALT/NEU/
```

wobei `s` für „substitute“ (= ersetzen) steht.

Mit Zeichenklassen wie `[ab]` kann entweder nach `a` oder `b` gesucht werden.
Das Zeichen `^` steht für den Anfang der Zeile und `$` steht für das Ende der Zeile:
```
┌──(kali㉿kali)-[~]
└─$ echo 'jhdfkjh' | sed 's/^j/_/' 
_hdfkjh
```

```
┌──(kali㉿kali)-[~]
└─$ echo 'jhdfkj' | sed 's/j$/_/' 
jhdfk_
```
Dadurch können Suchmuster genauer eingeschränkt werden.
 
 **ERE(Extended Regular Expressions)**
 erweitert die normalen REGEX um zusätzliche Funktionen:
 ```
 grep -E
 sed -E
 ```
Zusätzliche Operatoren sind:
```
eins|zwei   => Alternative
( )         => Gruppierung von Ausdrücken
{3}         => genau 3 Wiederholungen
{2,5}       => zwischen 2 und 5 Wiederholungen
```
Mit **Backreferenzen** kann auf zuvor gefundene Gruppe verwiesen werden:
```
(abbb)\1
```
Hierbei steht `\1` für den Inhalt der ersten Gruppe. Analog dazu verweiden `\2` und `\3` auf die zweite bzw. dritte Gruppe.

**PCRE**

PCRE bieten zusätzliche Funktionen und können mit:
```
grep -P
```
verwendet werden.

**Greedy und Non-Greedy**
Greedy versucht möglichst viele Zeichen zu matchen, während Non-Greedy möglichst wenige Zeichen erfassen.

 Schreibe einen shell Einzeiler mit dem man die Anzahl der Unterverzeichnisse im aktuellen Verzeichnisse zählt.

Tipp: Directories haben in der `ls -l` Ausgabe ganz am Beginn ein `d`.

---

Die Lösung ist:
```
┌──(kali㉿kali)-[~]
```

## 5. Übung (sed)

**Löse mit sed:**
- **Entferne alle `#` die sich am Ende der Zeile befinden**
- **Entferne alle `#` die sich am Anfang der Zeile befinden**
- **Füge `===` am Beginn jeder Zeile ein**
- **Füge `()` rund um jedes Wort ein. Ein Wort ist definiert als mindestens ein nicht-Leerzeichen.**

---

Um alle `#` am Ende der Zeile zu entfernen gibt man im Terminal ein:
```
sed 's/#$//'
```
denn das `$` kennzeichnet das Ende der Zeile.

Um alle `#` am Anfang der Zeile zu entfernen gibt man folgendes ein:
```
sed 's/^#//'
```
Denn das `^` markiert den Anfang einer Zeile.

Um `===` am Beginn jeder Zeile einzufügen muss man eingeben:
```
sed 's/^/===/'
```
Da `^` den Anfang einer Zeile darstellt und dort dann `====` eingefügt wird.

Um `()` um jedes Wort einzufügen muss man folgendes eingeben:
```
sed -E 's/([^]+)/(\1)/g'
```
Mit `([^ ]+)` wird jedes Wort erkannt. Das gefundene Wort wird in einer Gruppe gespeichert und mit `\1` wieder ausgegeben. Durch `(\1)` wird das Wort anschließend in Klammern gesetzt.

## 6. Übung (Datum)

**Mit sed. Datum re-formatieren von `YYYY-MM-TT` auf `TT.MM.YYYY`. `01/12/2020`-> `12.01.2020`. Das Datum kann sich an beliebiger Position in der Zeile befinden.**

---

Also wir brauchen `sed -E` damit wir die Extended Regular Expressions haben. Danach werden Tag, Monat und Jahr in 3 Gruppen aufgeteilt  und dann macht man Verweise auf diese Gruppe aber dreht diese um damit der Tag zuerst vorkommt.

Daraufhin muss man ein Datum in Amerikanischer weise eingeben und bekommt dann die Ausgabe in normaler Datumsangabe:
```
┌──(kali㉿kali)-[~]
└─$ sed -E 's#([0-9]{2})/([0-9]{2})/([0-9]{4})#\2.\1.\3#g'
01/12/2020
12.01.2020
```

Das `g` soll daraufhin alle Datumsangaben in dieser Zeiele ersetzten!
