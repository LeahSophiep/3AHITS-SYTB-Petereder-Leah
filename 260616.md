## Zusammenfassung der Theorie

### While-Schleife

Die while-Schleife wird verwendet, um einen Programmteil so lange zu wiederholen, wie eine bestimmte Bedingung erfüllt ist.

Wie zum Beispiel hier:
```
counter=1
while [ $counter -le 10 ]   # <= 10
do
    echo $counter
    ((counter++))
done
```
Man könnte auch stattdessen diese Zeile verwenden `while ((counter<= 10))` verändern, diese ist die einfachere und simplere Variante.

In diesem Beispiel wird die Variable `counter` so lange erhöht bis sie 10 erreicht und dann wird mit `done` signalisiert das man fertig ist.

### For-Schleife

Wird zum Beispiel hier verwendet:
```
# for
echo "---for---"
# Liste = durch white-spaces getrennter string
data="1 2 3 4 5 6 7"
for d in $data
do
    echo $d
done
```

Die `for` Schleife dient hierbei dazu die Werte nacheinander zu verarbeiten. Hier wird die Variable `data` erstellt die einen String mit Zahlen enthält die mit Leerzeichen getrennt sind. Die Schleife speichert hierbei jeden Wert einzelnd in die Variable `d` und gibt ihn danach aus.

### Kommandozeilenargumente

Ein Beispiel zu Kommandozeilenargumente:
```
echo "---Kommandozeilenargumente---"
for arg in $@
do 
    echo $arg
done
```
Hier ist das wesentliche das `$@`, denn mit diesem Ausdruck werden alle Argumente angesprochen, die am Anfang übergeben wurden. Die `for` Schleife läuft durch die Argumente und gibt sie aus. Nun kann der Benutzer etwas eingeben und es muss nicht vorher im Programm festgelegt werden.

### Brace Expansion

Hierbei ist das Beispiel:
```
# brace expansion {}
for value in {20..25}
do
    echo $value
done
```
Die `Brace Expansion` erzeugt automatisch eine Zahlenfolge. Hier in diesem Beispiel werden durch den Ausdruck `{20...25}` die Zahlen von 20 bis 25 erzeugt. Danach wird wieder mit der `for` Schleife jeder dieser Zahlen ausgegeben.

### Internal Field Seperator

Das Beispiel hierfür ist:
```
echo "--- field seperator ---"
mylist="hallo Zeynep,hello Zeynep,guten tag"
IFS="," # internal field seperator
for el in $mylist
do
    echo $el
done
```
Der `Internal Field Seperator` legt das Trennzeichen fest, welches einen Ausdruck in einzelne zerlöegt. In diesem Beispiel wird das Trennzeichen `,` festgelegt. Hierbei wird dann jeder Ausdruck nach einem `,` abgespaltet von den anderen.

## 2. Übung (Summe und Maximum)

**Schreibe ein bash Skript das eine beliebige Menge von positiven Zahlen als Argumente aus der Kommandozeile übernimmt. Es soll die Summe und die größte Zahl ausgegeben werden. Hinweis: Verwende `#@`.**

---

Hier auch wieder eine skript Datei erstellen `touch sumandmax.sh` und diese auch wieder mit `chmod +x sumandmax.sh` ausführbar machen.

Die Lösung für das Skript ist dann folgende:
```
#!/bin/bash

sum=0
max=0

for zahl in $@
do
    ((sum += zahl))

    if (( zahl > max ))
    then
        max=$zahl
    fi
done

echo "Summe: $sum"
echo "Maximum: $max"
```

Also es werden erstmal die zwei Variablen `sum` und `max` definiert und danach werden mit `for` die Argumente durchlaufen, die der Bentuzer im Terminal eingegeben aht, dies passiert mit `$@`. Diese Zahlen werden alle in die Varibale `zahl` reingespeichert

Danach wird mit der Varibale `sum` alle Zahlen aufeinanderaddiert. Es wird dann jeder Wert überprüft, ob er denn größer als die Zahl ist die gerade in der Variable `max` gespeichert ist. Sollte dies der Fall sein, so wird die neue Zahl in `max` gespeichert. Ist dies nicht der Fall geht die for Schleife weiter.

Daraufhin werden nach der Schleife die Summe sowie das Maximum ausgegeben.

Die Ausgabe ist dann so:
```
┌──(kali㉿kali)-[~]
└─$ ./sumandmax.sh 67 5 10 13 77
Summe: 172
Maximum: 77
```
